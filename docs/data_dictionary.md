# Словарь данных

## Таблицы

### customers: клиенты
| Поле | Тип | Описание |
|---|---|---|
| customer_id | INTEGER, PK | Уникальный идентификатор абонента |
| region_id | INTEGER, FK → regions | Регион обслуживания |
| tariff_id | INTEGER, FK → tariffs | Текущий тарифный план |
| segment | TEXT | `B2C` (физлица) или `B2B` (бизнес) |
| age | INTEGER | Возраст, лет. Допустимо 14–100, остальное считается ошибкой |
| activation_date | TEXT (YYYY-MM-DD) | Дата подключения |
| churn_date | TEXT (YYYY-MM-DD) | Дата отключения. `NULL` = клиент активен |

### monthly_usage: использование и выручка по месяцам
Гранулярность: один клиент за один месяц. Бизнес-ключ: `(customer_id, month)`.

| Поле | Тип | Описание |
|---|---|---|
| usage_id | INTEGER, PK | Технический идентификатор строки |
| customer_id | INTEGER, FK | Клиент |
| month | TEXT | Первое число месяца (YYYY-MM-01) |
| data_gb | REAL | Использованный интернет-трафик, ГБ |
| minutes | INTEGER | Использованные минуты |
| sms | INTEGER | Отправленные SMS |
| revenue | REAL | Выручка за месяц, тенге (абонплата + перерасход) |

### tariffs: тарифы
| Поле | Тип | Описание |
|---|---|---|
| tariff_id | INTEGER, PK | Идентификатор тарифа |
| tariff_name | TEXT | Эконом / Стандарт / Комфорт / Премиум |
| monthly_fee | INTEGER | Абонентская плата, тенге в месяц |
| data_gb_limit | INTEGER | Включённый интернет, ГБ |
| minutes_limit | INTEGER | Включённые минуты |

### regions: регионы
| Поле | Тип | Описание |
|---|---|---|
| region_id | INTEGER, PK | Идентификатор региона |
| region_name | TEXT | Название региона |

### support_tickets: обращения в поддержку
| Поле | Тип | Описание |
|---|---|---|
| ticket_id | INTEGER, PK | Идентификатор обращения |
| customer_id | INTEGER, FK | Клиент |
| created_date | TEXT | Дата обращения |
| category | TEXT | Категория: Качество связи, Биллинг, Тариф, Интернет, Другое |
| resolved_days | INTEGER | Дней до решения |

## Витрины (представления)

| Витрина | Источник | Правила очистки |
|---|---|---|
| `clean_usage` | monthly_usage | 1) дубликаты по `(customer_id, month)` → оставляем строку с минимальным `usage_id`; 2) `data_gb` вне диапазона 0–1000 исключаем; 3) строки с `revenue IS NULL` исключаем |
| `clean_customers` | customers | 1) возраст вне 14–100 → `NULL`; 2) `churn_date < activation_date` → `NULL` |

Обновление: витрины пересчитываются при каждом обращении (обычные `VIEW`).

## Бизнес-глоссарий метрик

| Метрика | Определение |
|---|---|
| **Выручка** | Сумма `revenue` по `clean_usage` за период |
| **ARPU** | Average Revenue Per User: выручка за месяц / число уникальных абонентов с начислениями в этом месяце |
| **Активные на начало месяца** | Клиенты с `activation_date` раньше начала месяца и без отключения или с отключением не раньше начала месяца |
| **Churn rate (месячный)** | Клиенты, отключившиеся в месяце / активные на начало месяца, % |
| **Churn (за год)** | Доля клиентов с `churn_date` до 01.01.2026 от всех подключённых, % |
| **Retention (k)** | Доля клиентов когорты, у которых есть начисления на k-й месяц жизни. Когорта = месяц первого начисления |
| **Перерасход** | Выручка сверх абонплаты: 100 ₸ за ГБ сверх лимита и 2 ₸ за минуту сверх лимита |
| **Парето 80/20** | Минимальный набор сегментов, дающий 80 % выручки |
